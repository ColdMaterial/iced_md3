<h1 align="center">Iced MD3</h1>


<div align="center">
  Implementation of the <a href="https://m3.material.io">Material Design 3</a> system for the <a href="https://iced.rs/">Iced GUI library</a>
</div>


> [!WARNING]
> This branch is compatible with Iced 14.0, and will not have any new features added. It will
> receive bug fixes as long as the [Chilen](https://github.com/tpaau/chilen) project stays on Iced
> 14.0.
>
> You can use the [`main`](https://github.com/ColdMaterial/iced_md3) branch, which is currently in
> the process of migration to the `master` branch of Iced.
